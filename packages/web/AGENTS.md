# OMEGA Web (@omega.js/web)

The framework for a brand's marketing site and authenticated frontend — the UJM successor rebuilt on Eleventy 3 + LiquidJS, with layered themes, the section/component library, the asset pipeline, and the `omega` CLI for the whole consumer lifecycle.

The guide for this package lives at [docs/web/index.md](../../docs/web/index.md); cross-framework contracts live in [docs/shared/](../../docs/shared/). In a consumer project, the same knowledge ships inside the installed package and the omega Claude plugin's hooks inject it by context — do not copy content here; this file stays a pointer.
