Asset layers

Each page-specific asset loads in three layers, in order: Global → Theme → Consumer. All three are the same pages/<path> file, just from different sources. Each layer turns its own dot green when it loads; a red dot means that layer has no file for this page (the normal state for layers nobody customized).

Page-specific CSS

  • Global (framework default)
  • Theme (active theme)
  • Consumer (your project)

Page-specific JS

  • Global (framework default)
  • Theme (active theme)
  • Consumer (your project)
