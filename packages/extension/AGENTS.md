# OMEGA Extension (@omega.js/extension)

The framework for building modern cross-browser extensions (Chrome, Firefox, Edge, Opera, Brave) — one-line-import bootstrap per context, a component-based architecture, a multi-browser build/release pipeline, auto-translation, and cross-context auth sync.

The guide for this package lives at [docs/extension/index.md](../../docs/extension/index.md); cross-framework contracts live in [docs/shared/](../../docs/shared/). In a consumer project, the same knowledge ships inside the installed package and the omega Claude plugin's hooks inject it by context — do not copy content here; this file stays a pointer.
