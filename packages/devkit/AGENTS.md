# OMEGA Devkit (@omega.js/devkit)

The shared build-time internals for the OMEGA frameworks — a private workspace package, vendored into published frameworks at prepare time and never published itself.

The guide for this package lives at [docs/devkit/index.md](../../docs/devkit/index.md); cross-framework contracts live in [docs/shared/](../../docs/shared/). In a consumer project, the same knowledge ships inside the installed package and the omega Claude plugin's hooks inject it by context — do not copy content here; this file stays a pointer.
