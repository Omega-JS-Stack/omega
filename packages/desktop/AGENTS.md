# OMEGA Desktop (@omega.js/desktop)

The framework for building modern Electron desktop apps — one-line-import bootstrap per Electron process, a modular feature library with file-based extensibility, a multi-platform build/release pipeline, and a built-in test framework.

The guide for this package lives at [docs/desktop/index.md](../../docs/desktop/index.md); cross-framework contracts live in [docs/shared/](../../docs/shared/). In a consumer project, the same knowledge ships inside the installed package and the omega Claude plugin's hooks inject it by context — do not copy content here; this file stays a pointer.
