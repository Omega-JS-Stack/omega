# OMEGA Client (@omega.js/client)

The browser-side utility library with Firebase integration — a singleton `Manager` exposing auth, reactive DOM bindings, Firestore, storage, notifications, Sentry, `omega.request()`, and the standalone icon/motion modules the frameworks embed.

The guide for this package lives at [docs/client/index.md](../../docs/client/index.md); cross-framework contracts live in [docs/shared/](../../docs/shared/). In a consumer project, the same knowledge ships inside the installed package and the omega Claude plugin's hooks inject it by context — do not copy content here; this file stays a pointer.
