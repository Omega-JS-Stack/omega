# OMEGA Backend (@omega.js/backend)

The framework for building modern Firebase Cloud Functions backends — one `Manager.init(exports, {...})` bootstrap wiring built-in functions, helper classes, payment integrations, Firestore-trigger pipelines, an MCP server, and the `omega` CLI.

The guide for this package lives at [docs/backend/index.md](../../docs/backend/index.md); cross-framework contracts live in [docs/shared/](../../docs/shared/). In a consumer project, the same knowledge ships inside the installed package and the omega Claude plugin's hooks inject it by context — do not copy content here; this file stays a pointer.
